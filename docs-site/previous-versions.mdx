This site documents Routr 3, the current release. Documentation for older versions stays frozen on the previous site.

## Routr 2

Routr 2 gets fixes only. They are released from the [`v2` branch](https://github.com/fonoster/routr/tree/v2) as 2.34.x versions: on npm under the `v2` dist-tag (`npm install @routr/sdk@v2`) and on Docker Hub under their version tag (`fonoster/routr-one:2.34.2`), never as `latest`. To move to Routr 3, see [Upgrade from Routr 2 to Routr 3](/guides/upgrade-to-routr-3).

## Source code for any version

Every release is tagged in the repository. Browse or check out a tag to get the exact source of a version:

- [Tags](https://github.com/fonoster/routr/tags)
- [Releases](https://github.com/fonoster/routr/releases)

This command checks out the source of a specific release:

```bash
git clone https://github.com/fonoster/routr
cd routr
git checkout v2.25.0
```
