## Source code for any version

Every release is tagged in the repository. Browse or check out a tag to get the exact source of a version:

- [Tags](https://github.com/fonoster/routr/tags)
- [Releases](https://github.com/fonoster/routr/releases)

This command checks out the source of a specific release:

```bash
git clone https://github.com/fonoster/routr
cd routr
git checkout v2.25.0
```
