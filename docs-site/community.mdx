## Getting help

Ask support questions in Discord or GitHub Discussions, not in the issue tracker. Keep issues for bugs and feature requests, and use the bug report template so maintainers can reproduce the problem.

<Note>
  Please don't ask individual maintainers for support directly. Questions in the public channels help everyone who hits the same problem later.
</Note>

## Contributing

Contributions of every kind are welcome: code, docs, issue triage, and answering questions. Read the [contributing guide](/contributing) before you open a pull request. For large or controversial changes, start a discussion on Discord or GitHub Discussions first.

## Office hours

Technical discussions happen on Discord and GitHub Discussions. Maintainers also hold open office hours; join the Discord server and follow the announcements channel for the next one.

## Code of conduct

Routr follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in the project's spaces is expected to keep it welcoming and harassment-free.
