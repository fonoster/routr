The `routr/routr-connect` chart deploys EdgePort, Message Dispatcher, Connect processor, Location Service, API Server (pgdata), Registry, Requester, and optionally RTPRelay. It can also deploy PostgreSQL and Redis from the Bitnami charts.

| Chart | Version | App version |
| --- | --- | --- |
| `routr-connect` | `0.4.3` | `2.13.6` |

Image tags default to the chart's app version.

## Install

These commands add the chart repository and install a release named `routr` in the `routr` namespace.

```bash
helm repo add routr https://routr.io/charts
helm repo update
kubectl create namespace routr
helm install routr routr/routr-connect --namespace routr
```

This command overrides values from a file.

```bash
helm install routr routr/routr-connect --namespace routr -f values.yaml
```

## Notes

- `global.otlExporter` sets `OTEL_EXPORTER_JAEGER_ENDPOINT`, but the Routr services read the standard `OTEL_EXPORTER_OTLP_ENDPOINT`. See [Environment variables](/reference/environment-variables).
- The chart does not set `TRUSTED_EDGEPORT_ADDRESSES` on the Connect processor. With more than one EdgePort replica, requests forwarded between EdgePorts go through routing and access checks again. See [Connect processor](/reference/components/connect).
- The chart has no values for Connect settings such as `ENFORCE_E164` or the Connect Token verifier.
